# Beta readiness checklist

## Implemented in Milestone 6

- Authenticated moderator queue for post and knowledge reports.
- Moderator resolve, dismiss, and remove-content actions with audit events.
- Moderation appeals with reviewer assignment and resolution state.
- Report and appeal rate limits.
- Suspended-account field and moderator authorization helper.
- Privacy-safe success metric definitions.

## Required before sign-off

- Run a manual WCAG 2.2 AA keyboard and screen-reader audit on supported browsers.
- Run the responsive audit on mobile, tablet, and desktop devices.
- Execute load, backup/restore, deletion-propagation, and security tests against staging and record results.
- Recruit the agreed closed-beta cohort and record consent, participant roles, findings, and retention evidence.
- Review beta evidence and decide whether to expand, narrow, or revise scope.

These external and environment-dependent checks must not be represented as complete without evidence.
