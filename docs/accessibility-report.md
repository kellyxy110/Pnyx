# Accessibility report

## Automated evidence

The current application includes semantic `main` landmarks, a skip link, visible focus styles, native form controls, labels, status roles, keyboard-operable buttons, and reduced-motion CSS. These are repository observations, not a substitute for axe or screen-reader execution.

Automated browser/axe execution is pending because no Playwright/axe browser runner is currently installed in the project.

## Required execution

- Run axe against sign-up, sign-in, feed, Spaces, Explore, Knowledge, AI, moderation, and profile routes.
- Verify headings, landmarks, form errors, dialogs, menus, status announcements, contrast, focus visibility, zoom, text resizing, and reduced motion.
- Run keyboard-only flows for authentication, posting, replying, searching, reporting, moderation, and account deletion.

READY FOR HUMAN VERIFICATION: manual screen-reader and device review.
