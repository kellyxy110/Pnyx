# Manual release QA checklist

## Human verification required

- [ ] Keyboard-only navigation on authentication, Spaces, feed, Explore, Knowledge, AI, moderation, profile, notifications, and account deletion.
- [ ] Screen-reader review with a supported desktop browser and mobile assistive technology.
- [ ] Lighthouse review on critical routes.
- [ ] Mobile, tablet, laptop, and wide desktop visual review.
- [ ] Reduced motion, 200% zoom, text resizing, and high-contrast review.
- [ ] Resend test to the Resend-account email using `onboarding@resend.dev`.
- [ ] OAuth callback review after credentials are configured.
- [ ] Closed-beta consent, feedback, bug reporting, and privacy review.
- [ ] Isolated backup/restore exercise.
- [ ] Beta evidence review and release decision.

Do not mark a checkbox complete without date, environment, tester, browser/device, and evidence link.
