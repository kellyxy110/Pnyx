# Pnyx Brand Implementation

The Pnyx foundation follows the supplied brand guide poster.

## Tokens

- Midnight Navy `#0B1F3A`: primary brand, headings, navigation, and primary actions.
- Aegean Blue `#2563EB`: links, focus states, interactive states, and supporting emphasis.
- Ancient Gold `#D4A017`: accents, highlights, key actions, and the knowledge emphasis in the hero.
- Teal `#0EA5A5`: supporting data and healthy/operational status indicators.
- Stone Grey `#94A3B8`: neutral metadata, borders, and disabled states.
- Ivory `#F8FAFC`: readable page background.

## Typography

The UI requests Geist/Inter first with a system fallback, uses a restrained display treatment for emphasis, and preserves the guide’s strong navy headings, medium subheadings, and readable body text.

## Accessibility

Color is never the only status signal. Focus uses Aegean Blue, status labels retain visible text, and the ivory/navy base preserves a high-contrast reading surface. Responsive behavior and reduced-motion support remain required by `design.md` and `definition-of-done.md`.
